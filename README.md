## Overview

ServiceHub is a full-stack home services marketplace connecting customers, service professionals and businesses through a centralized digital platform.

**Live Website:** [Visit ServiceHub](https://servicehub-mauve.vercel.app/)

## Key Features

| Module | Features |
|---|---|
| Customer | Search, booking, saved services and reviews |
| Provider | Verification, service management and quotations |
| Business | Employee, inventory and tool management |
| Admin | User management, approvals and audit logs |
| Communication | Messaging and notifications |
| Finance | Payment integration, invoices and commissions |
| Analytics | Revenue, booking and performance reports |

## Tech Stack

- **Frontend:** React.js, JavaScript, Tailwind CSS
- **Backend:** Supabase, PostgreSQL, Edge Functions
- **Authentication:** Supabase Auth, Role-Based Access
- **Payments:** Razorpay
- **Analytics:** Recharts
- **Deployment:** Vercel
- **Version Control:** Git & GitHub

## Installation

    git clone https://github.com/mauryashivangi271/servicehub.git
    cd servicehub
    npm install

Create a `.env.local` file:

    VITE_SUPABASE_URL=your_supabase_url
    VITE_SUPABASE_PUBLISHABLE_KEY=your_publishable_key

Start the application:

    npm run dev

Full functionality requires a configured Supabase database, security policies and backend functions.
